## 结论

工程闭环可运行，但 Flash 非思考模式下的开放仓库维护能力偏弱。175 题全部进入真实 API 执行并完成评分，113 题给出补丁或弃答，62 题最终耗尽轮次。73 份补丁都可以应用到对应基准快照，内容正确性仍需单独判断。

官方数值规则下，综合分 **25.61/100**，决策准确率 **53.71%**。这是 DocChange API 工具适配协议的工程基线，不能称为原样官方 Docker/CLI 排行榜成绩。

SCIDOCS 的较低分数显示 BM25 对这一语义关联任务的限制。两套数据都是英文科学文献检索，它们不能证明技术文档修改正确，也不能代表中文问答质量。此次没有 Dense/Rerank 的同集对照，不报告相应提升。

## 补丁是否有用

73/73 通过 `git apply --check`，只涉及允许的文档后缀；审计前后工作树保持干净，未把候选自动应用到源码。这证明补丁格式、基准上下文与写入范围有效，不能证明语义正确。

73 份中，63 份对应确实需要修改的任务，10 份在应弃答任务中产生了不必要修改。63 份经 rubric 逐条评分：57 份得到部分或全部准则分，6 份零分，15 份没有阻断 P0，1 份达到 rubric100分。**这些数值不等于57份可直接发布。**

以下为对现有补丁的三例抽查，没有修改补丁或重新生成：

- **Mautic cron lifetime，70分：** 加入 `--time-limit`、`--memory-limit` 和消息数限制说明，确实补充了原任务所需的运行边界。但遗漏关联队列文档与“当前消息处理完再退出”的行为；仍把命令放在 PHP 高亮代码块。另有“短于15分钟间隔”的文字与900秒示例相等的问题。作为草稿有用，仍需修订。[原补丁](dogbench-2026-11-02/patches/mautic-user-documentation-pr358.patch)
- **Azure workload identity，0分：** 修改了贡献者与 CI 说明，却没有覆盖 rubric 要求的安装和认证入口。体现“找到了相关文档”与“找全正确维护面”的差距。[原补丁](dogbench-2026-11-02/patches/Azure-azure-service-operator-pr4003.patch)
- **Doc Detective，rubric100分：** 实际只修正 `creatr → create` 拼写。保留型准则全部通过，并不证明已完成输入描述的功能更新。这是评分规则的局限，不能用这一个100分案例宣称功能维护完全正确。[原补丁](dogbench-2026-11-02/patches/doc-detective-doc-detective-pr21.patch)

全部73份补丁及逐份分数、P0条件、修改路径、裁判摘要见 [补丁清单](dogbench-2026-11-02/patch-assessments.csv)。[完整评分 JSON](dogbench-2026-11-02/scores.json)保留每条准则的证据与失败原因。[175题 CSV](dogbench-2026-11-02/tasks.csv)包含失败和实际请求次数。

## 协议、恢复和费用

评分复用原始 Terra prompt、JSON Schema、证据引用校验及数值 scorer，裁判为 `gpt-5.6-terra` / high。CLI 使用 read-only、关闭插件与工具、最多两次评分尝试；没有执行上游默认的 bypass-sandbox。63 个正确修改决策进入内容裁判；错误决策与执行失败按官方规则直接计零。

本机采用 API 工具白名单，未使用上游原生 Docker/CLI 隔离。对精确发布输入中的 prose-overlap finding 保留但兼容准入；17个参考树采用工具层不可遍历符号链接政策，3个仓库旧名经 GitHub repository ID 绑定。任务、prompt、树、代码 blob 和评分规则未改写。原始 context audit 通过95题、标记80题；两个子集综合分分别24.37、27.61，见[元数据与敏感性结果](dogbench-2026-11-02/summary.json)。两者都不是独立排行榜成绩。

此次含网络中断和多批次恢复，已经完成的语义决定不重生成；因此不是一次无中断的首试成功率。四批共1979次真实 API 请求，另有101次费用预检拦截后的轮次预留被计入旧任务预算。这会压低部分任务可用轮次，也是后续修正的明确工程问题。逐题实际请求与预留轮次均已导出，不能把它们混算。

1979次请求中46次 usage 未知，保留预留费用。按[当日官方高峰价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)、计缓存命中优惠并保留未知预留，估算上界约9.59元；忽略缓存的保守账本值28.82元不是实际扣费。接口预试2次另计上界0.0743元。Codex裁判的订阅额度消耗未折算人民币；没有租卡或充值。
