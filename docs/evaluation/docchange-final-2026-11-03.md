## 完成的项目能力

保留 React + FastAPI、SQL RunStore、Outbox/Redis Streams、Revision/ChangeSet、hash绑定审批与版本冲突检查。仓库Agent新增带来源的维护计划、逐edit要求/证据关联、独立上下文覆盖复核及最多一轮定向修补；计划、工具回执、候选和阶段可持久恢复。仓库工具按授权读取，精确编辑只允许作用于已观察原文；临时Git Index生成候选，不修改用户原工作树。
